# Dissertation Project: Neural Representation and Control of Manifolds in the Brain


## Aims

Two aims of the present project: 
1. to provide a self-supervised methodology to train continuous attractor neural networks (CANs)
2. to embed CANs in a control circuit model and demonstrate the methodology on the Drosophila steering circuit.


## Quick guide into reading this repo

Check /Notes for notes
Check /Network\_models for model architectures
Check /SimulateDatasets for data simulation utilities
Check /utils for plotting tools etc.
